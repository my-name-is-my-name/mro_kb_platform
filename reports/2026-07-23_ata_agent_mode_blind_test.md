# Blind-тест агентского режима поиска ATA

Дата: 2026-07-23

## Методика

В Go/No-Go переданы только описание и тип ВС из реестра исторических заявок. Исторический результат не передавался в запрос и не использовался при определении ATA.

## Проверенный новый пример

Запрос «Устранение царапин в районе приемника статического давления», Airbus A320:

- каталог определил ATA 34;
- основание: совпадение с версионируемым синонимом компонента;
- итог: `need_more_info`;
- система запросила размеры/координаты и фотографии повреждения.

## Вывод

Агентский режим должен пополняться не новыми условиями Python-кода, а подтверждёнными записями каталога: компонент/синоним → ATA → источник (AMM/IPC/CMM) → тип ВС и ревизия. До появления подтверждённого источника неизвестный компонент остаётся в статусе экспертной проверки.
