# Политика источников для ATA Impact Agent

1. Нумерация и словарь ATA: лицензированная ATA iSpec 2200 / ATA Standard Numbering System. Не копировать закрытое содержание в репозиторий без права распространения.
2. Подтверждение конкретной работы: OEM AMM, SRM, IPC, CMM, ALS и утверждённые данные, загруженные через контролируемый ingestion с ревизией, применимостью ВС/MSN и правами доступа.
3. EASA/FAA AD, правила и публичные материалы: только дополнительный регуляторный контекст. Они не заменяют OEM-процедуру.
4. Интернет не используется на рабочем пути обработки заявки. Новые материалы сначала проходят проверку экспертом, классификацию источника и индексацию.

Публичные ориентиры: [ATA standards](https://ataebiz.org/standards/), [ATA Technical Data Working Group](https://ataebiz.org/WG-technical-data/), [EASA continuing airworthiness](https://www.easa.europa.eu/en/document-library/easy-access-rules/online-publications/easy-access-rules-continuing-airworthiness?erules-id=ERULES-1963177438-729).
